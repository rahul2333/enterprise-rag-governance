# EU AI Governance Notes

The platform is designed around risk management, access control, traceability, human oversight, and data protection.

Phase 1 foundations:

- Role-based access control.
- Classification metadata on documents.
- Access groups for retrieval filtering.
- Audit log schema for accountable events.
- Review queue and risk register schemas.

Later phases add PII detection, prompt injection logging, evaluation reports, and human-review workflows.
