# IT Security Policy

Document classification: Internal
Source department: Information Security
Access group: all-employees
Version: 1.0

## Personal Cloud Storage

Employees must not store company documents in personal cloud storage accounts. Approved enterprise storage must be used for internal, confidential, and restricted material.

Examples of personal cloud storage include consumer file-sync accounts, private email inboxes, personal drives, and unmanaged collaboration spaces.

## Approved Storage

Approved enterprise storage must support:

- Company identity login.
- Central access revocation.
- Encryption in transit and at rest.
- Audit logging.
- Data retention policies.

## Device Security

Company-managed devices must run endpoint protection, disk encryption, and operating-system security updates. Lost or stolen devices must be reported to IT Security immediately.

## Access Reviews

Managers must review privileged access at least quarterly. Access that is no longer required must be removed within five business days.

## Exceptions

Exceptions require written approval from IT Security and must include business justification, expiration date, and compensating controls.
